## 1. 通用类型

### 1.1 ApiResult

通用 API 响应包装，所有接口都经过此格式。

```typescript
interface ApiResult<T = any> {
  success: boolean       // 请求是否成功
  data?: T               // 响应数据（加密时返回 string，可选）
  isEncrypted?: boolean  // data 是否经过三重 Base64 加密
  errorCode?: number     // 错误码（0=成功）
  message?: string       // 错误消息
}
```

| 字段 | 类型 | 必填 | 说明 |
|:-----|:----|:----:|------|
| `success` | `boolean` | ✅ | `true` 表示成功 |
| `data` | `T` | ❌ | 明文 JSON 或加密字符串（可选） |
| `isEncrypted` | `boolean` | ❌ | `true` 时需执行 `decodeMultiBase64` |
| `errorCode` | `number` | ❌ | 错误码 |
| `message` | `string` | ❌ | 失败时的错误描述 |

**解密流程**：

```
data(string) → atob() × 3 → TextDecoder('utf-8') → JSON.parse → 原始数据
```

### 1.2 toCamelCase 转换

`request()` 函数对所有 API 响应执行 `toCamelCase()` 转换，snake_case 字段自动映射为 camelCase：

| snake_case | camelCase |
|:-----------|:----------|
| `topic_id` | `topicId` |
| `like_count` | `likeCount` |
| `create_time` | `createTime` |
| `comment_count` | `commentCount` |
| `user_id` | `userId` |
| `cover_url` | `coverUrl` |
| `remote_url` | `remoteUrl` |
| `key_path` | `keyPath` |
| `lite_content` | `liteContent` |
| `video_time_length` | `videoTimeLength` |
| `search_type` | `searchType` |
| `total_page` | `totalPage` |
| `reply_id` | `replyId` |
| `commend_list` | `commendList` |

## 2. 用户类型

### 2.1 UserInfo

用户认证信息（存储在 localStorage）。

```typescript
interface UserInfo {
  uid: string           // 用户 ID
  token: string         // 认证令牌
  nickname?: string     // 用户昵称
}
```

| 字段 | 类型 | 说明 | 来源 |
|:-----|:----|------|:----:|
| `uid` | `string` | 用户唯一标识 | 登录响应 `user.id` |
| `token` | `string` | API 认证令牌 | 登录响应 `token` |
| `nickname` | `string` | 用户昵称（可选） | 登录响应 `user.nickname` |

### 2.2 FollowUser

关注列表中的用户。

```typescript
interface FollowUser {
  userId: number
  nickname: string
  avatar: string
  description: string
  fansCount: number
  isFavorite: boolean
  tagNames: string[] | null
  vip: number
  certified: boolean
  certVideo: boolean
  certProfessor: boolean
  famous: boolean
  status: number
  title: { id: number; name: string; consume: number; consumeEnd: number; icon: string }
}
```

## 3. 帖子类型

### 3.1 Topic

```typescript
interface Topic {
  topicId: number
  title: string
  user: TopicUser | null
  content: string            // HTML 格式正文
  attachments: Attachment[]
  likeCount: number
  createTime: string         // 创建时间（已转换为 camelCase）
  node: Node | null
  commentCount: number
  doors: DoorData[]
  sale?: SaleData
  isFavorite?: boolean
}

interface TopicUser {
  id: number
  nickname: string
  avatar: string
}

interface LiteTopic extends Topic {
  liteContent: string
}
```

### 3.2 Attachment

```typescript
interface Attachment {
  id: number
  remoteUrl: string         // 远程地址（需要解码）
  category: string          // 分类: "image" | "video" | ...
  status: number
  coverUrl: string          // 封面地址
  video_time_length: number // 视频时长（注意：snake_case）
  keyPath: string
}
```

### 3.3 CommentItem

```typescript
interface CommentItem {
  userId: number            // 用户 ID
  nickname: string          // 用户昵称
  floor: number             // 楼层
  avatar: string            // 头像
  attachments: string       // 附件
  certVideo: boolean        // 认证视频
  replyId: number           // 回复 ID
  createTime: string        // 创建时间
  content: string           // 评论内容
  commendList: CommentItem[] // 子评论列表
}
```

### 3.4 TopicListResponse / SearchResponse

```typescript
interface TopicListResponse {
  results: TopicItem[]
  page: {
    total: number    // 总数
    page: number     // 当前页
    limit: number    // 每页条数
  }
}

interface SearchResponse {
  results: TopicItem[]
  page: {
    total: number
    page: number
    limit: number
  }
}
```

## 4. 登录类型

### 4.1 LoginParams

```typescript
interface LoginParams {
  username: string         // 邮箱或用户名
  password: string         // 明文密码
  captchaCode?: string     // 验证码（可选）
  captchaId?: string       // 验证码 ID（可选）
  ref?: string             // 来源（可选）
}
```

### 4.2 LoginResponse

```typescript
interface LoginResponse {
  token: string            // 认证令牌
  user: UserCurrent        // 用户信息（独立接口）
  domain: string           // 大陆域名
  domainAbroad: string     // 海外域名
  customerService: string  // 客服邮箱
  ref: string              // 来源
  type: number             // 用户类型
  vip_domain: string       // VIP 域名（注意：snake_case）
}

interface UserCurrent {
  id: number
  nickname: string
  avatar: string
  description: string
  topicCount: number
  videoCount: number
  commentCount: number
  fansCount: number
  favoriteCount: number
  status: number
  sex: number
  vip: number
  vipExpiresTime: string
  tags: Array<any> | null
  role: number
  phone: string
  gold: number
  topicLikeNum: number
  username: string
  email: string
  emailVerified: boolean
  createTime: string
  lastLoginTime: string
  lastLoginIp: string
}
```

### 4.3 字段映射表

| LoginResponse 字段 | 用途 | 存储位置 |
|:------------------|:-----|:---------|
| `user.id` | UID | `settings store.uid` |
| `token` | 认证令牌 | `settings store.token` |
| `user.nickname` | 界面展示 | `settings store.nickname` |
| `domain` | API 主机 | `settings store.apiBase` |

## 5. 任务类型

### 5.1 TaskStatus

任务状态（含签到状态）。

```typescript
interface TaskStatus {
  goldSignIn: {
    open: boolean
    status: boolean   // true=可执行(未签到), false=已完成(已签到)
    num: number
  }
}
```

| 字段 | 类型 | 说明 |
|:-----|:----|------|
| `goldSignIn.open` | `boolean` | 签到功能是否开启 |
| `goldSignIn.status` | `boolean` | `true`=可执行（未签到），`false`=已完成（已签到） |
| `goldSignIn.num` | `number` | 签到次数 |
