## 1. 页面分类

### 1.1 主页面（TabBar页面）

底部TabBar显示的页面，用户可通过TabBar在不同功能模块间切换。

**判定标准**：路由配置 `meta: { showTabBar: true }`

**当前主页面**：

| 页面组件 | 路由路径 | 功能说明 |
|---------|---------|---------|
| HotTopicsView | `/hot` | 热门帖子列表，支持Tab切换 |
| NodeView | `/node` | 板块导航，网格布局 |
| SearchView | `/search` | 搜索功能，支持热门标签 |
| SettingsView | `/settings` | 用户配置、认证信息、功能入口 |

### 1.2 子页面（非TabBar页面）

从主页面或其他子页面跳转的页面，不显示底部TabBar。

**判定标准**：路由配置不设置 `showTabBar` 或设置为 `false`

**当前子页面**：

| 页面组件 | 路由路径 | 功能说明 |
|---------|---------|---------|
| TopicView | `/topic/:pid?` | 帖子详情，含视频、评论、收藏、分享 |
| UserHomeView | `/homepage/:userId` | 用户主页，含用户信息、帖子列表、关注按钮 |
| UserView | `/user/:userId?` | 用户帖子列表 |
| NodeTopicsView | `/node/:nodeId` | 板块下的帖子列表 |
| FollowView | `/settings/follow` | 关注列表，支持搜索和取消关注 |
| ImageViewerView | `/image-viewer` | 图片查看器 |
| LoginView | `/login` | 登录页面 |
| HistoryView | `/history` | 浏览历史记录 |
| FavoritesView | `/favorites` | 收藏列表 |
| NotFoundView | `/:pathMatch(.*)*` | 404页面 |

## 2. 主页面规范

### 2.1 结构要求

主页面必须包含以下结构：

1. **sticky头部区域**：使用 `position: sticky` 固定在顶部
2. **内容区域**：帖子列表使用 Topics 组件，其他内容使用对应组件
3. **滚动位置管理**：使用 `onActivated`/`onDeactivated` 保存和恢复滚动位置

### 2.2 路由配置

```typescript
{
  path: '/xxx',
  name: 'Xxx',
  component: () => import('@/views/XxxView.vue'),
  meta: { showTabBar: true },
}
```

### 2.3 缓存策略

- 必须在 `App.vue` 的 `keep-alive :include` 列表中添加组件名
- 使用 `defineOptions({ name: 'XxxView' })` 显式指定组件名

### 2.4 滚动位置管理

**使用Map缓存多个Tab的滚动位置**：

```typescript
const scrollMap: Record<number, number> = {}

onActivated(() => {
  nextTick(() => {
    window.scrollTo({ top: scrollMap[activeTab.value] || 0 })
  })
})

onDeactivated(() => {
  scrollMap[activeTab.value] = window.scrollY
})
```

## 3. 子页面规范

### 3.1 结构要求

子页面必须包含以下结构：

1. **导航栏**：使用 `van-nav-bar`，配置返回按钮
2. **内容区域**：根据功能选择合适的组件
3. **Loading状态**：使用 `van-skeleton` 或 `ref(true)` 控制

### 3.2 路由配置

```typescript
{
  path: '/xxx/:id',
  name: 'Xxx',
  component: () => import('@/views/XxxView.vue'),
}
```

### 3.3 导航栏配置

```vue
<van-nav-bar
  :title="页面标题"
  left-text="返回"
  left-arrow
  @click-left="onClickLeft"
  :fixed="true"
  :placeholder="true"
/>
```

**关键属性**：
- `:fixed="true"`：固定定位
- `:placeholder="true"`：自动添加占位高度

### 3.4 返回按钮实现

```typescript
import { useSafeBack } from '@/utils/navigation'

const safeBack = useSafeBack()
const onClickLeft = () => safeBack()
```

### 3.5 缓存策略

**按需缓存**：只有需要保留状态的子页面才加入 `keep-alive :include` 列表

当前已缓存的子页面：
- `FollowView`：关注列表，从设置页进入后返回保留状态
- `NodeTopicsView`：板块帖子列表，切换板块时保留滚动位置

### 3.6 滚动位置管理

**非缓存页面**：每次进入自动重置到顶部（默认行为）

**缓存页面**：使用 `sessionStorage` 保存和恢复滚动位置

```typescript
onActivated(() => {
  const saved = Number(sessionStorage.getItem('scrollPos_Xxx') || '0')
  sessionStorage.removeItem('scrollPos_Xxx')
  if (saved > 0) {
    nextTick(() => window.scrollTo(0, saved))
  }
})

onDeactivated(() => {
  sessionStorage.setItem('scrollPos_Xxx', String(window.scrollY))
})
```

## 4. 通用规范

### 4.1 数据加载模式

**主页面（多Tab场景）**：

```typescript
const topicsMap: Record<number, DataType[]> = {}
const pageMap: Record<number, number> = {}
const totalMap: Record<number, number> = {}

const loadPage = async (page: number) => {
  loading.value = true
  const tab = activeTab.value
  const result = await api.getXxx({ params: { tabIndex: tab, page, limit: pageSize } })
  if (result.success) {
    topicsMap[tab] = result.data.results
    pageMap[tab] = page
    totalMap[tab] = result.data.page.total
  }
  loading.value = false
}
```

**子页面（单条数据）**：

```typescript
watch(() => route.params.id, async (newId) => {
  if (newId) await loadData(newId as string)
}, { immediate: true })
```

**子页面（列表数据）**：

```typescript
const loadPage = async (page: number) => {
  loading.value = true
  const resp = await api.getXxx({ params: { page, limit: pageSize } })
  if (resp.success) {
    topics.length = 0
    topics.push(...resp.data.results)
    totalItems.value = resp.data.page.total
    pageIndex.value = page
  }
  loading.value = false
}
```

### 4.2 错误处理

```typescript
const resp = await api.getXxx({ params: { id } })
if (!resp.success) {
  showToast(resp.message || '加载失败')
  loading.value = false
  return
}
```

### 4.3 Loading状态

- 使用 `ref(true)` 管理 loading 状态
- 在 API 调用前设为 `true`，完成后设为 `false`
- 骨架屏组件根据 loading 状态显示

### 4.4 样式约定

**页面容器**：

```css
.xxx-container {
  min-height: 100vh;
  background: #f7f8fa;
}
```

**Sticky头部**：

```css
.xxx-header-sticky {
  position: sticky;
  top: 0;
  z-index: 99;
  background: #fff;
}
```
