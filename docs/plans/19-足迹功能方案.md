## 1. 需求概述

在配置页新增"足迹"入口，点击跳转独立足迹页面。足迹页面顶部用 Tab 切换"用户"和"帖子"两个分类，分别展示对应的浏览记录。记录包含标题（用户昵称/帖子标题）和访问时间，支持去重（同 ID 只保留最新一条）和清空。

## 2. 数据结构

### HistoryItem

```ts
interface HistoryItem {
  type: 'user' | 'topic'
  id: string
  title: string    // 用户昵称或帖子标题
  time: number     // Date.now()
}
```

## 3. Store 设计

### 新建 `src/stores/history.ts`

- **State**: `records: HistoryItem[]`（持久化 localStorage key `history`）
- **Computed**:
  - `userRecords` — 过滤 `type === 'user'`，按 `time` 倒序
  - `topicRecords` — 过滤 `type === 'topic'`，按 `time` 倒序
- **Actions**:
  - `addRecord(type, id, title)` — 插入/更新记录；同 `type + id` 去重，更新时间并移到最前；最大 100 条，超出截断尾部
  - `removeRecord(type, id)` — 删除单条
  - `clearRecords()` — 清空全部

## 4. 路由

在 `src/router/index.ts` 新增：

```ts
{
  path: '/history',
  name: 'History',
  component: () => import('@/views/HistoryView.vue'),
}
```

加入 `publicPages` 数组（无需登录）。

## 5. 足迹页面

### 新建 `src/views/HistoryView.vue`

- **顶部** `van-nav-bar`：标题"足迹"，左侧返回箭头（`safeBack`），右侧"清空"文字按钮
- **Tab 切换**：`van-tabs` + `van-tab`，两个 tab：`用户` / `帖子`
- **列表**：每个 tab 内用 `van-cell-group` + `van-cell` 展示
  - 用户 tab：title = 昵称，label = `uid: {id}`，点击跳转 `/homepage/:id`
  - 帖子 tab：title = 帖子标题，label = `pid: {id}`，点击跳转 `/topic/:id`
- **空列表**：`van-empty description="暂无足迹"`
- **删除**：每条 cell 外层 `van-swipe-cell`，左滑显示红色删除按钮

## 6. 入口

### 修改 `src/views/SettingsView.vue`

在"数据来源" cell-group 下方新增：

```html
<van-cell-group inset class="history-group">
  <van-cell title="足迹" is-link @click="router.push('/history')">
    <template #right-icon><van-icon name="arrow" /></template>
  </van-cell>
</van-cell-group>
```

## 7. 埋点

在以下页面的适当位置调用 `historyStore.addRecord()`：

| 文件 | 时机 | type | id | title |
|------|------|------|----|-------|
| `src/views/UserView.vue` | `onMounted` | `user` | `userId` | `'用户 ' + userId` |
| `src/views/UserHomeView.vue` | `loadUserInfo` 成功后 | `user` | `userId` | `userInfo.nickname` |
| `src/views/TopicView.vue` | `loadTopic` 成功后 | `topic` | `pid` | `topicLocal.title` |
