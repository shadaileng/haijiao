## 1. 需求概述

在用户主页（UserHomeView）添加关注/取消关注切换按钮，参考原始项目 `haijiao-wxt` 的实现方式。

---

## 2. API 端点

| 方法 | 端点 | 说明 | 参数 |
|------|------|------|------|
| GET | `/user/favorite` | 关注/取消关注 | `targetId=用户ID`, `opt=add/rm` |
| GET | `/user/info/{uid}` | 获取用户信息（含 `isFavorite` 关注状态） | 路径参数 |

### 2.1 关注用户

**请求：**
```http
GET /user/favorite?targetId=12345&opt=add
```

**响应：**
```json
{
  "isEncrypted": false,
  "errorCode": 0,
  "message": "",
  "success": true,
  "data": null
}
```

### 2.2 取消关注

**请求：**
```http
GET /user/favorite?targetId=12345&opt=rm
```

**响应：**
```json
{
  "isEncrypted": false,
  "errorCode": 0,
  "message": "",
  "success": true,
  "data": null
}
```

### 2.3 检查关注状态

通过 `/user/info/{uid}` 返回的 `isFavorite` 字段判断当前用户是否已关注该用户。

**响应（部分）：**
```json
{
  "isFavorite": true
}
```

## 3. 类型定义

无需额外类型定义，`checkFollow` 返回 `{ isFollow: boolean }` 对象。

---

## 4. API 层修改

在 `src/api/request.ts` 的 `api` 对象中添加：

```typescript
// 关注用户
addFollow(params: { params: { userId: string | number } }): Promise<ApiResult>

// 取消关注
cancelFollow(params: { params: { userId: string | number } }): Promise<ApiResult>

// 检查关注状态
checkFollow(params: { params: { userId: string | number } }): Promise<ApiResult>
```

实现：

```typescript
async addFollow({ params }: { params: { userId: string | number } }) {
  try {
    const data = await request({
      url: '/user/favorite',
      params: { targetId: params.userId, opt: 'add' }
    })
    return { success: true, data }
  } catch (e: any) {
    return { success: false, message: e.message }
  }
},

async cancelFollow({ params }: { params: { userId: string | number } }) {
  try {
    const data = await request({
      url: '/user/favorite',
      params: { targetId: params.userId, opt: 'rm' }
    })
    return { success: true, data }
  } catch (e: any) {
    return { success: false, message: e.message }
  }
},

async checkFollow({ params }: { params: { userId: string | number } }) {
  try {
    const data = await request({
      url: '/user/info/' + params.userId
    })
    return { success: true, data: { isFollow: !!data?.isFavorite } }
  } catch (e: any) {
    return { success: false, message: e.message }
  }
},
```

## 5. UI 设计

### 5.1 布局结构

```
┌─────────────────────────────────────┐
│  用户信息卡片（已有）                │
│  头像 | 昵称 | ID                   │
│  帖子:0  粉丝:240  关注:98          │
│  签名:...              [关注] ← 右上角 │
├─────────────────────────────────────┤
│  分割线                              │
├─────────────────────────────────────┤
│  帖子列表...                        │
└─────────────────────────────────────┘
```

关注按钮使用绝对定位，位于 `.user-info-wrapper` 右上角（`top: 50%; right: 16px; transform: translateY(-50%)`），垂直居中于用户信息卡片。

### 5.2 按钮状态

| 状态 | 显示文本 | 按钮样式 | 说明 |
|------|---------|---------|------|
| 未关注 | 关注 | primary | 可点击 |
| 已关注 | 已关注 | default | 可点击，点击后取消关注 |
| 加载中 | 加载中 | loading | 禁用 |
| 自己 | 隐藏 | - | 不显示按钮 |

### 5.3 交互流程

1. **页面加载时**：
   - 检查是否是自己的主页（`userId === currentUserId`）
   - 如果不是自己，调用 `checkFollow` API 获取关注状态
   - 根据结果显示按钮状态

2. **点击关注按钮**：
   - 如果未关注 → 调用 `addFollow` API
   - 如果已关注 → 调用 `cancelFollow` API
   - 成功后切换按钮状态
   - 失败时显示 Toast 提示

3. **关注状态缓存**：
   - 使用 `userStore.follow` 列表缓存关注关系
   - 关注/取消关注后更新缓存

## 7. 注意事项

1. **不能关注自己**：隐藏按钮或禁用
2. **未登录处理**：未登录时点击关注按钮提示"请先登录"
3. **错误处理**：API 调用失败时显示 Toast 提示
4. **并发保护**：请求进行中时禁用按钮，防止重复点击
5. **粉丝数更新**：关注/取消关注后更新用户信息中的粉丝数
