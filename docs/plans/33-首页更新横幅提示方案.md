## 1. 需求背景

帖子列表被 `keep-alive` 缓存时，从详情返回需要保持滚动位置。当前 `onActivated` 只在首次加载时请求数据，导致用户看到的是缓存的旧数据。

需要一种机制：在保持滚动位置的同时，检测新内容并提示用户刷新。

## 2. 实现方案

### 2.1 设计原则

- **数据驱动**：Topics 是纯展示组件，不涉及数据请求
- **职责分离**：父组件负责数据请求和状态管理，Topics 负责比较和显示
- **接口简洁**：Topics 只接收数据 prop，通过 emit 事件通知父组件

### 2.2 核心逻辑

1. **比较逻辑**（Topics 内部）：`baselineFirstId` vs `topics[0].topicId` → 计算 `newCount`
2. **数据请求**（父组件）：`onActivated` 时请求最新数据 → 存到 `latest` 变量
3. **应用更新**（父组件）：点击横幅 → 用 `latest` 替换当前数据

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
```

### 2.4 接口定义

```typescript
// Topics props
baselineFirstId: string | number  // 上次首条 ID，用于内部比较
topics: LiteTopic[]               // 当前显示的数据
latest: { topics: LiteTopic[]; total: number } | undefined  // 最新数据

// Topics emit
'apply'  // 点击横幅时触发，父组件用 latest 替换当前数据
```

### 2.5 横幅显示规则

| 条件 | 显示内容 |
|------|----------|
| newCount = 0 | 不显示横幅 |
| newCount ≤ pageSize (20) | "有 X 条新内容，点击查看" |
| newCount > pageSize | "有 20+ 条新内容，点击查看" |

### 2.6 交互行为

- 点击横幅 → emit `apply` 事件，父组件用 `latest` 替换当前数据
- 切换 tab/板块/文件夹 → `latest` 变化，重新比较

## 5. 代码变更

### 5.1 Topics.vue（通用组件）

```typescript
// 新增 props
baselineFirstId: { type: [String, Number], default: undefined }
latest: { type: Object as PropType<{ topics: LiteTopic[]; total: number }>, default: undefined }

// 新增状态
const newCount = ref(0)
const lastFirstId = ref<string | number>()

// 新增 emit
const emit = defineEmits(['load', 'pageChange', 'apply'])

// 点击横幅
const onBannerClick = () => {
  emit('apply')
  lastFirstId.value = undefined
  newCount.value = 0
}

// watch 比较逻辑（不变）
watch(() => props.topics, (newTopics) => {
  if (props.pageIndex !== 1 || !props.baselineFirstId || newTopics.length === 0) {
    newCount.value = 0
    return
  }
  const currentFirstId = newTopics[0].topicId
  if (!lastFirstId.value) {
    lastFirstId.value = currentFirstId
    if (currentFirstId === props.baselineFirstId) {
      newCount.value = 0
      return
    }
  }
  if (currentFirstId === props.baselineFirstId) {
    newCount.value = 0
    lastFirstId.value = currentFirstId
    return
  }
  const oldIndex = newTopics.findIndex(t => t.topicId === props.baselineFirstId)
  const count = oldIndex === -1 ? newTopics.length : oldIndex
  newCount.value = count > props.pageSize ? props.pageSize : count
}, { immediate: true })

// baselineFirstId 变化时重置
watch(() => props.baselineFirstId, () => {
  lastFirstId.value = undefined
  newCount.value = 0
})
```

```html
<!-- 模板 -->
<div v-if="newCount > 0" class="new-banner" @click="onBannerClick">
  有 {{ newCount >= 20 ? '20+' : newCount }} 条新内容，点击查看
</div>
```

### 5.2 各视图通用模式

```typescript
// 1. 新增状态
const latest = ref<{ topics: LiteTopic[]; total: number }>()

// 2. 记录首条 ID（loadPage 中）
if (page === 1 && result.data.results.length > 0) {
  lastFirstTopicIdMap[tab] = result.data.results[0].topicId
}

// 3. 检测更新（onActivated 中）
const checkUpdate = async () => {
  const tab = activeTab.value
  if (!lastFirstTopicIdMap[tab]) return
  const result = await api.xxx({ params: { page: 1, limit: pageSize, ... } })
  if (!result.success || !result.data.results?.length) return
  const latestFirstId = result.data.results[0].topicId
  if (latestFirstId !== lastFirstTopicIdMap[tab]) {
    latest.value = {
      topics: result.data.results,
      total: result.data.page?.total || 0
    }
  }
}

// 4. 处理 apply 事件
const onApply = () => {
  if (latest.value) {
    topicsMap[tab] = latest.value.topics
    lastFirstTopicIdMap[tab] = latest.value.topics[0].topicId
    pageMap[tab] = 1
    totalMap[tab] = latest.value.total
    latest.value = undefined
  }
  nextTick(() => { window.scrollTo({ top: 0 }) })
}
```

```html
<!-- 模板 -->
<Topics
  :baselineFirstId="lastFirstTopicIdMap[key]"
  :topics="topicsMap[key]"
  :latest="latest"
  @apply="onApply"
/>
```

## 6. 边界情况

| 场景 | 处理方式 |
|------|----------|
| 首次加载（无 baselineFirstId） | 不显示横幅 |
| 请求失败 | 静默失败，不显示横幅 |
| 旧首条帖子已删除 | newCount = pageSize，显示 "20+" |
| 数据完全不变 | 不显示横幅 |
| 切换 tab/板块/文件夹 | baselineFirstId 变化，重置状态 |
| latest 被多次传入 | 始终使用最新传入的 latest |
