## 1. 背景

当前 FollowView（关注页）在 TabBar 中占用一个独立页签，路由 `/follow/:userId?`。但「关注」功能使用频率较低，不适合长期占用 TabBar 空间。将其迁移为配置页（Settings）的子页面，通过配置页内的 cell 进入。

## 2. 改动范围

| 文件 | 改动 |
|:-----|:------|
| `src/router/index.ts` | 新增 `/settings/follow` 路由（名 `SettingsFollow`）；移除旧的 `/follow` 路由 |
| `src/components/common/TabBar.vue` | 移除 `follow` tab 条目 |
| `src/views/SettingsView.vue` | 足迹 cell 下方新增「关注」cell，跳转 `/settings/follow` |
| `src/views/FollowView.vue` | 添加 `van-nav-bar`（`← 关注`，返回 `/settings`）；`onBeforeUnmount` 保存滚动位置 |
| `src/App.vue` | keep-alive 移除 `FollowView` |

## 3. 详细设计

### 3.1 路由变更

```typescript
// 移除
{ path: '/follow/:userId?', name: 'Follow', component: () => import('@/views/FollowView.vue'), meta: { showTabBar: true } }

// 新增
{ path: '/settings/follow', name: 'SettingsFollow', component: () => import('@/views/FollowView.vue') }
```

### 3.2 TabBar

移除 `follow` 条目，保留 3 个页签：主页、搜索、配置。

### 3.3 SettingsView

在「足迹」cell 下方新增 cell：

```vue
<van-cell title="关注" is-link @click="router.push('/settings/follow')">
  <template #right-icon><van-icon name="arrow" /></template>
</van-cell>
```

### 3.4 FollowView

添加 nav-bar 标题栏：

```vue
<van-nav-bar title="关注" left-arrow @click-left="() => router.push('/settings')" />
```

### 3.5 滚动位置恢复

FollowView 不在 keep-alive 中，导航到用户主页再返回时需要恢复滚动位置。

```typescript
import { onBeforeUnmount } from 'vue'
import { useRoute } from 'vue-router'

onBeforeUnmount(() => {
  sessionStorage.setItem(`scrollPos_SettingsFollow`, String(window.scrollY))
})
```

路由的 `scrollBehavior` 自动读取 `scrollPos_SettingsFollow` 并恢复：

```typescript
// router/index.ts 中已有的 scrollBehavior
const key = `scrollPos_${to.name as string}`
const savedPos = sessionStorage.getItem(key)
if (savedPos) {
  sessionStorage.removeItem(key)
  return { top: parseInt(savedPos) }
}
```
