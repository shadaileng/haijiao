## 1. 背景与目标

### 1.1 现状问题

当前 `SettingsView.vue` 布局从上到下依次为：

| 序号 | 模块 | 控件类型 |
|:---:|------|---------|
| 1 | UserInfo 卡片 | 自定义组件 |
| 2 | 我的钱包（金币/钻石大卡片 + 签到按钮） | van-cell-group（含自定义 div） |
| 3 | 登录状态 / 退出登录 | van-cell-group |
| 4 | 认证配置 | van-cell-group |
| 5 | 镜像源 | van-cell-group |
| 6 | 数据来源 | van-cell-group |
| 7 | 收藏 / 足迹 / 关注 | van-cell-group（页面底部） |

**存在问题：**

- 钱包卡片只有金币、钻石两个数字字段，却占据整个 cell-group + 自定义布局，视觉占比过大
- 签到按钮放在 cell 内但用的是 `van-button`，与整体 cell 风格不统一
- 收藏/足迹/关注放在页面最底部，需滚动很远才能访问

### 1.2 优化目标

1. 金币/钻石数据整合进 UserInfo 组件，作为用户信息的一部分 inline 显示
2. 签到按钮改用纯 `van-cell` 控件，与其他 cell 风格统一
3. 收藏/足迹/关注上移到用户信息紧下方，减少滚动距离
4. 收藏/足迹/关注仅登录后显示（个人功能，未登录无数据）
5. 精简登录状态：去掉"登录状态"cell，未登录仅"去登录"，已登录变"退出登录"

### 1.3 目标布局

| 序号 | 模块 | 控件类型 | 登录限制 |
|:---:|------|---------|:--------:|
| 1 | UserInfo 卡片（含金币/钻石 inline） | 自定义组件 | 仅登录 |
| 2 | 签到 | van-cell-group | 仅登录 |
| 3 | 收藏 / 足迹 / 关注 | van-cell-group | 仅登录 |
| 4 | 去登录 / 退出登录 | van-cell-group | 始终 |
| 5 | 认证配置 | van-cell-group | 始终 |
| 6 | 数据源配置（镜像源 + 数据来源） | van-cell-group | 始终 |

## 3. 详细设计

### 3.1 UserInfo 组件改造

**新增 prop：**

```ts
wealth?: { gold: number; diamond: number }
```

**模板改动：**

在签名（`user-info-sign`）下方新增一行，当 `wealth` 有值时显示：

```html
<div v-if="wealth" class="user-info-wealth">
  <span class="wealth-gold">金币 {{ wealth.gold }}</span>
  <span class="wealth-diamond">钻石 {{ (wealth.diamond / 100).toFixed(2) }}</span>
</div>
```

**样式：**

```css
.user-info-wealth {
  display: flex;
  gap: 16px;
  font-size: 0.85rem;
  line-height: 1.4;
}
.wealth-gold { color: #ff9900; }
.wealth-diamond { color: #00ccff; }
```

与现有 `user-info-stats` 保持一致的 `flex + gap` 布局，字体大小 `0.85rem`，视觉上作为用户信息的补充行。

### 3.2 SettingsView 布局调整

#### 3.2.0 移除导航栏返回按钮

当前 `van-nav-bar` 带有 `left-arrow` 和 `@click-left="safeBack"`，配置页是顶级页面，无需返回。

变更前：
```html
<van-nav-bar title="配置" left-arrow @click-left="safeBack" />
```

变更后：
```html
<van-nav-bar title="配置" />
```

移除 `left-arrow` 和 `@click-left="safeBack"`，同时可删除 `useSafeBack` 导入和 `safeBack` 变量。

#### 3.2.1 删除钱包 cell-group

删除 `wallet-group` 整个 `van-cell-group`（原第 123-148 行），包括：
- "我的钱包" 标题 cell
- 自定义 `wallet-content` div（金币/钻石大卡片）
- 签到按钮 cell

同时删除对应的 `<style>` 中 `.wallet-group`、`.wallet-content`、`.wallet-item`、`.wallet-label`、`.wallet-value` 相关样式。

#### 3.2.2 移动收藏/足迹/关注

将 `history-group`（原第 190-200 行）移动到 UserInfo skeleton 后面（即 `<van-skeleton>` 结束标签之后），并添加 `v-if="settings.isLoggedIn"`：

```html
<van-cell-group v-if="settings.isLoggedIn" inset class="history-group">
  <van-cell title="收藏" is-link @click="router.push('/favorites')">
    <template #right-icon><van-icon name="arrow" /></template>
  </van-cell>
  <van-cell title="足迹" is-link @click="router.push('/history')">
    <template #right-icon><van-icon name="arrow" /></template>
  </van-cell>
  <van-cell title="关注" is-link @click="router.push('/settings/follow')">
    <template #right-icon><van-icon name="arrow" /></template>
  </van-cell>
</van-cell-group>
```

收藏、足迹、关注均为个人功能，未登录时无数据，显示无意义。

#### 3.2.3 签到 cell 独立分组

签到 cell 作为独立 `van-cell-group`，放在 UserInfo skeleton 之后、收藏/足迹/关注之前：

```html
<van-cell-group v-if="settings.isLoggedIn" inset class="signin-group">
  <van-cell
    :title="signedIn ? '今日已签到' : '立即签到'"
    :is-link="!signedIn"
    :loading="signInLoading"
    @click="handleSignIn"
  />
</van-cell-group>
```

- 已签到时显示"今日已签到"，无箭头，灰色文字
- 未签到时显示"立即签到"，有箭头，可点击
- 使用 `van-cell` 原生 `loading` 属性替代内嵌 `van-button`
- 独立 `van-cell-group` 包裹，与其他分组风格一致

#### 3.2.4 传递 wealth 数据

```html
<UserInfo v-if="currentUser" :userInfo="currentUser" :wealth="settings.isLoggedIn ? wealth : undefined" />
```


#### 3.2.5 精简登录状态 cell

当前 `status-group` 包含两个 cell：
- "登录状态" cell（显示"已登录"/"未登录" + UID 或提示）
- "退出登录" 或 "去登录" cell

精简为一个 `van-cell-group`，删除整个 `status-group`，替换为独立分组：

```html
<van-cell-group inset class="auth-group">
  <van-cell v-if="settings.isLoggedIn" title="退出登录" is-link @click="handleLogout">
    <template #right-icon><van-icon name="warning-o" color="#ee0a24" /></template>
  </van-cell>
  <van-cell v-else title="去登录" is-link @click="router.push('/login')">
    <template #right-icon><van-icon name="arrow" /></template>
  </van-cell>
</van-cell-group>
```

- 删除 `status-group` 整个 cell-group 及其样式
- 未登录时仅显示"去登录" cell
- 已登录时同一个位置变为"退出登录" cell（红色警告图标）
- 独立 `van-cell-group` 包裹，与其他分组风格一致
- 保留 `handleLogout` 函数不变

#### 3.2.6 合并镜像源与数据来源

当前 `mirror-group` 和 `info-group` 是两个独立 cell-group，功能相关（都是数据源配置），合并为一个 `van-cell-group`：

```html
<van-cell-group inset class="source-group">
  <van-cell title="镜像源（数据源地址）" :value="mirrorDisplay()" is-link @click="openConfig" />
  <van-cell title="数据来源">
    <template #label>
      <div>{{ settings.apiBase }}</div>
      <div class="source-hint">官方域名国内被屏蔽，请填写后台提供的可用镜像地址</div>
    </template>
  </van-cell>
</van-cell-group>
```

- 删除 `mirror-group` 和 `info-group` 两个 cell-group
- 新建 `source-group` 替代，包含镜像源配置入口 + 数据来源信息
- 合并对应的 `<style>` 为 `.source-group`

#### 3.2.7 粘贴 Token 后加载用户信息

粘贴 Token 后自动获取用户信息并显示 UserInfo 卡片：

```ts
async function handlePasteCredentials() {
  try {
    const text = await navigator.clipboard.readText()
    const data = JSON.parse(text)
    if (data.uid && data.token) {
      settings.setCredentials(data.uid, data.token)
      showSuccessToast('Token 已粘贴')
      loadingUser.value = true
      try {
        await Promise.all([loadCurrentUser(), loadWealth(), loadSignInStatus()])
      } catch (e) {
        console.warn('load data failed:', e)
      }
      loadingUser.value = false
    } else {
      showToast('剪贴板内容格式无效')
    }
  } catch {
    showToast('读取剪贴板失败或格式无效')
  }
}
```

- 粘贴成功后设置 `loadingUser = true` 显示骨架屏
- 并行加载用户信息、金币/钻石、签到状态
- 加载完成后 `loadingUser = false`，UserInfo 卡片自动显示

### 3.3 变更对照表

| 变更项 | 变更前 | 变更后 |
|--------|--------|--------|
| 导航栏 | `left-arrow` + `safeBack` | 仅标题，无返回按钮 |
| 金币/钻石位置 | 独立钱包卡片（大区域） | UserInfo 组件内 inline 显示 |
| 签到控件 | `van-cell` 内嵌 `van-button` | 独立 `van-cell-group` |
| 收藏/足迹/关注位置 | 页面最底部，始终显示 | UserInfo 紧下方，仅登录显示 |
| 钱包 cell-group | 独立一组 | 删除 |
| 登录状态 cell-group | 两个 cell（状态+操作） | 独立 `van-cell-group`（去登录/退出登录切换） |
| 镜像源 + 数据来源 | 两个独立 cell-group | 合并为一个 cell-group |
| 粘贴 Token | 仅保存凭证 | 保存凭证后自动加载用户信息 |

## 4. 影响范围

- **无路由变更**：所有路由保持不变
- **无状态变更**：stores 无需修改
- **无 API 变更**：数据来源不变，只是展示位置调整
- **组件接口变更**：`UserInfo.vue` 新增可选 prop `wealth`，向后兼容
