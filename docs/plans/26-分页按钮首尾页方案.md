## 1. 背景

项目中所有分页均使用 Vant 4 的 `van-pagination` 组件。该组件仅提供上一页/下一页和页码按钮，不支持一键跳转首页和尾页。当总页数较多时，用户需要多次点击才能到达首页或末页。

## 2. 需求

在现有分页组件基础上，增加首页按钮（固定显示「1」）和尾页按钮（显示最后一页的页码数字），点击后直接跳转到对应页。

## 3. 现状分析

| 使用位置 | 组件 | 影响页面 |
|----------|------|----------|
| `src/components/Topics.vue:130` | `van-pagination` | HotTopicsView、SearchView、UserView、UserHomeView、FavoritesView、NodeTopicsView |
| `src/components/Comment.vue:31` | `van-pagination` | 帖子详情页评论区 |

## 4. 方案设计

### 4.1 新建通用 Pagination 组件

创建 `src/components/Pagination.vue`，完全自定义实现，不依赖 `van-pagination` 内部逻辑。

#### 布局结构

```
[上一页] [1] ... [p-1] [p] [p+1] ... [n] [下一页]
```

- 「上一页」/「下一页」：位于数字区域两侧，禁用态为灰色 + 半透明
- 数字区域：首页「1」和尾页「n」始终显示在数字区域内
- 「...」：可点击按钮，点击后翻一页（左侧...上一页，右侧...下一页）

#### 页码显示规则

| 总页数 | 当前页位置 | 显示内容 |
|:------:|:----------:|----------|
| ≤ 5 | 任意 | `[1][2][3][4][5]`（全部显示） |
| > 5 | 靠前（p ≤ 3） | `[1][2][3][4][5]...[n]` |
| > 5 | 居中 | `[1]...[p-1][p][p+1]...[n]` |
| > 5 | 靠后（p ≥ n-2） | `[1]...[n-4][n-3][n-2][n-1][n]` |

核心原则：
- 1 和 n 始终显示
- 至少显示 5 个页码按钮
- 「...」始终为可点击按钮，具有翻页功能

#### "..." 按钮逻辑

- 左侧「...」：点击后跳转到 `current - 1`
- 右侧「...」：点击后跳转到 `current + 1`

效果：每次点击「...」相当于翻一页，逐步接近首页或尾页。

#### Props 接口

```ts
{
  modelValue: number       // 当前页码（v-model）
  totalItems: number       // 总条数
  itemsPerPage: number     // 每页条数
}
```

#### Events

```ts
'update:modelValue': (page: number) => void
'change': (page: number) => void
```

#### 样式实现

使用 Vant CSS 变量保持与项目 UI 一致：

```css
--van-pagination-height: 40px
--van-pagination-item-width: 36px
--van-pagination-item-default-color: #1989fa
--van-pagination-background: #f7f8fa
--van-pagination-item-disabled-color: #969799
--van-pagination-item-disabled-background: #f7f8fa
```

激活态：白色文字 + 蓝色背景
禁用态：灰色文字 + 灰色背景 + 0.5 透明度
