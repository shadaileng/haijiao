## 1. 需求概述

在帖子详情页（`TopicView`）的统计行中添加分享按钮，点击后将帖子标题、链接、来源文案复制到剪贴板，方便用户粘贴分享给好友。

## 2. 复制内容格式

```
{帖子标题}

{帖子完整链接}

来自「海角助手」
```

示例：

```
请问这个功能怎么实现？

https://haijiao.example.com/topic/12345

来自「海角助手」
```

## 3. 技术方案

### 3.1 变更文件

| 文件 | 变更类型 | 说明 |
|------|---------|------|
| `src/views/TopicView.vue` | 修改 | 添加分享按钮 + 复制逻辑 |

### 3.2 实现步骤

#### 步骤 1：导入 useClipboard

在 `TopicView.vue` 的 `<script setup>` 中导入已有的 `useClipboard` composable：

```ts
import { useClipboard } from '@/composables/useClipboard'
const { copy } = useClipboard()
```

#### 步骤 2：添加分享函数

```ts
const handleShare = async () => {
  const url = `${window.location.origin}/topic/${topicLocal.value.topicId}`
  const text = `${topicLocal.value.title}\n\n${url}\n\n来自「海角助手」`
  const ok = await copy(text)
  if (ok) {
    showToast('链接已复制')
  } else {
    showToast('复制失败')
  }
}
```

#### 步骤 3：在统计行添加分享图标

在现有统计行（标签 / 评论 / 点赞 / 收藏）的最后添加分享列：

```html
<van-col span="6" class="hv-topic-state" @click="handleShare">
  <van-icon name="share" />
</van-col>
```

### 3.3 链接拼接规则

使用 `window.location.origin` 拼接完整 URL，确保：
- 开发环境：`http://localhost:5173/topic/12345`
- 生产环境：`https://haijiao.example.com/topic/12345`

### 3.4 复用现有组件

- `useClipboard`（`src/composables/useClipboard.ts`）：已有的剪贴板复制封装
- `showToast`（Vant）：已有的全局提示组件
- `.hv-topic-state`（`src/styles/global.scss`）：已有的统计行样式

## 4. 不涉及的变更

- 不创建新文件
- 不使用 Web Share API（仅复制链接）
- 不涉及 API 层、Worker 层、路由层
