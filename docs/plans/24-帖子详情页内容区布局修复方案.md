## 1. 问题描述

使用 Playwright 调试 `/topic/2213238` 页面时，发现帖子详情页内容区域（包含视频封面和正文）宽度塌陷为0，视频封面图片虽然已解码（base64 数据正常），但视觉上完全不可见。

|--------|-----|

| uid | `168****6501` |
| token | `d670d77fdbe840eeac8fe439bacbb095` |
| 帖子 PID | `2213238` |
| viewport | 375 × 812（iPhone 尺寸） |

## 2. 调试过程

### 2.1 使用 Playwright 脚本收集 DOM 状态

创建 `e2e/debug-topic-layout.mjs` 脚本，通过 `context.addInitScript()` 注入认证信息后导航到 `/topic/2213238`，收集关键元素的尺寸、样式和布局信息。

### 2.2 关键发现

**帖子内容区**（主贴 `.content`）：

```
.content                → width: 30px, height: 0px  ← 异常！
  └─ .hv-video-div     → width: 0px,  height: 0px  ← 被父级影响
       └─ img           → naturalW: 640, displayW: 0  ← 图片已解码但不可见
```

**评论区**（Comment `.content`）：

```
.comment-body > .content → width: 285px, height: 29px  ← 正常
```

对比可知，问题仅出现在主贴内容区，评论区正常。

### 2.3 根因定位

`TopicContent.vue` 的模板结构：

```html
<!-- TopicView.vue -->
<van-row class="hv-box-padding">      <!-- display: flex（Vant 默认） -->
  <TopicContent ... />                 <!-- .content 是 flex 子元素 -->
</van-row>
```

`.content` 样式（TopicContent.vue scoped）：

```css
.content {
  overflow: auto;     /* 创建 BFC，在 flex 上下文中不自动撑满 */
  text-align: left;
  font-size: 1.2rem;
  padding: 0 15px;    /* 30px padding，内容区 0px */
}
```

**问题链路**：

1. `<van-row>` 是 Vant flex 容器（`display: flex`）
2. `.content` 是 flex 子元素，有 `overflow: auto` 但**无显式宽度**
3. flex 算法将 `.content` 收缩为最小内容宽度（0px）
4. `.hv-video-div::after` 的 `padding-bottom: 56.25%` 基于父元素宽度 → 0px × 56.25% = 0px
5. 视频封面 img 的 `width: 100%` 继承父级 0px → 不可见

**对比评论区**：Comment.vue 中 `.content` 在 `.comment-body`（普通 `div`）内，不受 flex 影响，宽度正常。

---

## 3. 修复方案

在 `TopicContent.vue` 的 `.content` 样式中添加 `width: 100%`：

```css
.content {
  width: 100%;        /* 新增：flex 子元素撑满父容器 */
  overflow: auto;
  text-align: left;
  font-size: 1.2rem;
  padding: 0 15px;
}
```

### 影响范围分析

| 组件 | 使用 `.content` | 布局上下文 | 是否受影响 |
|------|:---:|------|:---:|
| `TopicContent.vue` | 是 | `<van-row>`（flex 容器） | 本次修复目标 |
| `Comment.vue` | 是 | `.comment-body`（普通 div） | 不受影响 |
| `ReplyList.vue` | 否（用 `.reply-text`） | — | 不受影响 |

两个组件均使用 Vue scoped styles，样式互相隔离，修复仅影响 TopicContent。
