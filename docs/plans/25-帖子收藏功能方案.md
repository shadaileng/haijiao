## 1. 需求概述

在帖子详情页添加收藏/取消收藏按钮，用户可将感兴趣的帖子加入收藏。收藏列表在设置页新增入口，点击进入独立页面查看已收藏的帖子。

## 2. API 参数（Playwright 调试结论）

通过 Playwright 调试原站 `https://hj2606029d3.top/post/details?pid=2193260`，捕获到原站收藏按钮的实际 API 调用：

| 端点 | 参数 | 说明 |
|------|------|------|
| `GET /api/favorite/add` | `entityId` + `entityType=topic` | 收藏帖子 |
| `GET /api/favorite/delete` | `entityId` + `entityType=topic` | 取消收藏 |
| `GET /api/favorite/favorite` | `entityId` + `entityType=topic` | 检查收藏状态，返回 `{ favorite: boolean }` |

**关键发现**：
- 参数名是 `entityId`（非 `topicId`），使用 `topicId` 会返回"收藏的内容不存在"
- `/favorite/favorite` 在当前后端用于**检查收藏状态**，非收藏列表
- 收藏列表接口暂未找到可用端点，后续需进一步调试

## 4. API 层

### 修改 `src/api/request.ts`

新增 5 个独立导出函数：

```ts
// 收藏帖子
export async function addFavorite(topicId: string | number, folderId?: number): Promise<any> {
  const params: Record<string, any> = { entityType: 'topic', entityId: topicId }
  if (folderId !== undefined) params.folderId = folderId
  return request({ url: '/favorite/v2/add', params })
}

// 取消收藏
export async function delFavorite(topicId: string | number): Promise<any> {
  return request({ url: '/favorite/v2/delete', params: { entityType: 'topic', entityIds: topicId } })
}

// 检查帖子是否已收藏
export async function checkFavorite(topicId: string | number): Promise<any> {
  return request({ url: '/favorite/favorite', params: { entityId: topicId, entityType: 'topic' } })
}

// 收藏夹列表
export async function getFavoriteFolders(): Promise<any> {
  return request({ url: '/favorite/v2/folderList', params: {} })
}

// 收藏夹内帖子列表（分页）
export async function getFavoriteTopics(
  page: number,
  limit = 20,
  folderId?: number,
  total?: number
): Promise<any> {
  const params: Record<string, any> = { page, limit }
  if (folderId !== undefined) params.folderId = folderId
  if (total !== undefined) params.total = total
  return request({ url: '/favorite/v2/topics', params })
}
```

在 `Api` 接口中新增：

```ts
export interface Api {
  // ...existing methods
  addFavorite(params: { params: { topicId: string | number; folderId?: number } }): Promise<ApiResult>
  delFavorite(params: { params: { topicId: string | number } }): Promise<ApiResult>
  checkFavorite(params: { params: { topicId: string | number } }): Promise<ApiResult>
  favoriteFolders(): Promise<ApiResult>
  favoriteTopics(params: { params: { page: number; limit?: number; folderId?: number; total?: number } }): Promise<ApiResult>
}
```

在 `api` 对象中注册：

```ts
export const api: Api = {
  // ...existing methods
  async addFavorite({ params }) {
    try {
      const data = await addFavorite(params.topicId)
      return { success: true, data }
    } catch (e: any) {
      return { success: false, message: e.message }
    }
  },
  async delFavorite({ params }) {
    try {
      const data = await delFavorite(params.topicId)
      return { success: true, data }
    } catch (e: any) {
      return { success: false, message: e.message }
    }
  },
  async checkFavorite({ params }) {
    try {
      const data = await checkFavorite(params.topicId)
      return { success: true, data }
    } catch (e: any) {
      return { success: false, message: e.message }
    }
  },
  async favoriteTopics({ params }) {
    try {
      const data = await getFavoriteTopics(params.page, params.limit)
      return { success: true, data }
    } catch (e: any) {
      return { success: false, message: e.message }
    }
  },
}
```

## 5. 帖子详情页

### 修改 `src/views/TopicView.vue`

**加载时检查收藏状态**：`loadTopic` 成功后调用 `checkFavorite` 初始化 `isFavorite`。

**操作栏**：在评论数、点赞数旁新增收藏按钮（star/star-o 图标）。

**交互逻辑**：
- 点击调用 `toggleFavorite`，未登录提示"请先登录"
- 已收藏 → 调用 `delFavorite`，取消后 `isFavorite = false`
- 未收藏 → 调用 `addFavorite`，收藏后 `isFavorite = true`
- API 失败时 showToast 提示，UI 不崩溃

**样式**：`.favorite-active { color: #ffc107; }` 已收藏显示黄色。

## 6. 收藏列表页

### 新建 `src/views/FavoritesView.vue`

复用 `Topics` 组件，分页加载收藏帖子。支持多收藏夹切换。

**API 调用流程**：
1. `onMounted` → `api.favoriteFolders()` → `/favorite/v2/folderList` → 获取收藏夹列表
2. 默认选中第一个收藏夹 → `api.favoriteTopics({ folderId, total })` → `/favorite/v2/topics` → 加载帖子
3. 用户切换收藏夹 → 重新加载对应收藏夹的帖子

**UI 结构**：
- 顶部 `van-nav-bar`：标题"我的收藏"，左侧返回箭头
- 收藏夹 tabs（仅多于 1 个时显示）：水平滚动，点击切换
- 帖子列表：复用 `Topics` 组件，`mode="pagination"`

```vue
<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { api } from '@/api/request'
import Topics from '@/components/Topics.vue'
import type { LiteTopic } from '@/types'
import { useSafeBack } from '@/utils/navigation'

interface Folder {
  id: number
  name: string
  count: number
}

const safeBack = useSafeBack()
const folders = ref<Folder[]>([])
const selectedFolder = ref<Folder | null>(null)
const topics = ref<LiteTopic[]>([])
const loading = ref(true)
const pageIndex = ref(1)
const totalItems = ref(0)
const pageSize = 20

const loadFolders = async () => {
  loading.value = true
  const resp = await api.favoriteFolders()
  if (resp.success && resp.data) {
    folders.value = resp.data as Folder[]
    if (folders.value.length > 0 && !selectedFolder.value) {
      selectFolder(folders.value[0])
    } else {
      loading.value = false
    }
  } else {
    loading.value = false
  }
}

const selectFolder = async (folder: Folder) => {
  selectedFolder.value = folder
  await loadPage(1)
}

const loadPage = async (page: number) => {
  if (!selectedFolder.value) return
  loading.value = true
  const resp = await api.favoriteTopics({
    params: { page, limit: pageSize, folderId: selectedFolder.value.id, total: selectedFolder.value.count }
  })
  if (resp.success && resp.data) {
    topics.value = resp.data.results || []
    totalItems.value = resp.data.page?.total || 0
    pageIndex.value = page
  }
  loading.value = false
}

onMounted(() => loadFolders())
const onPageChange = (p: number) => loadPage(p)
</script>

<template>
  <div class="favorites-view">
    <van-nav-bar title="我的收藏" left-arrow @click-left="safeBack" :fixed="true" :placeholder="true" />
    <div v-if="folders.length > 1" class="folder-tabs">
      <div v-for="folder in folders" :key="folder.id"
           class="folder-tab" :class="{ active: selectedFolder?.id === folder.id }"
           @click="selectFolder(folder)">
        {{ folder.name }} ({{ folder.count }})
      </div>
    </div>
    <Topics :topics="topics" :skeleton-loading="loading" mode="pagination"
            :page-index="pageIndex" :total-items="totalItems" :page-size="pageSize"
            @page-change="onPageChange" />
  </div>
</template>

<style scoped>
.favorites-view { min-height: 100vh; background: #f7f8fa; }
.folder-tabs { display: flex; gap: 8px; padding: 12px 16px; overflow-x: auto; background: #fff; }
.folder-tab { flex-shrink: 0; padding: 6px 12px; border-radius: 16px; font-size: 13px; background: #f7f8fa; color: #666; cursor: pointer; }
.folder-tab.active { background: #07c160; color: #fff; }
</style>
```
